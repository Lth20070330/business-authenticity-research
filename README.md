# 经营流水真实性识别与核查决策研究

以 2026 深圳国际金融科技大赛赛题四「刷单等非规范经营行为的识别」为起点，逐步构建可复现的数据集、识别方法和核查决策实验，支撑比赛报告与后续论文。

**当前状态：研究与实现框架，尚未采集研究数据、实现模型或产生实验结果。** 下文中的规模、方法和排期均为待验证方案，不代表已有成果。

## 研究主线

经营数据与核查证据 → 数据治理与标签 → 时间和关系特征 → 真实性识别 → 有限预算下的核查排序 → 真实验证与仿真压力测试。

优先研究「交易存在，但缺少真实经营依据」及其对经营收入判断的影响。流水文件篡改识别作为可选扩展。只有取得实际申请时点与相关证据后，才研究和声称识别「授信前美化」；电商刷评价、洗钱、盗刷和贷款违约不能直接作为本任务标签。

## 两人如何开始

1. 一起阅读研究边界，确认能否联系真实数据合作方、比赛截止时间和初步论文方向。
2. 在待办清单中认领任务：A 暂负责数据与证据，B 暂负责方法与实验；重要设计由另一人复核。
3. A 完成数据来源和字段可用性盘点；B 整理基线与无泄漏的评测协议。
4. 先验收一个能贯通「导入—核验—划分—基线—评估」的小样本流程，再扩大规模。

尚未选定 Python 依赖和运行环境，当前不提供虚构的运行命令。第一条实现流水线完成后，在此补充环境安装、数据准备和复现实验命令。

## 数据与发布

仓库初始为私有。默认只提交文档、代码、配置与不含敏感信息的模板；真实数据、账户标识、凭证和模型输出不提交。对外开放代码或数据前，分别核对相应授权和许可。比赛原始 PDF 暂不转载，要求摘要见成果文档，最终以主办方最新要求为准。

# 决策记录

## D001：建立文档优先的私有研究仓库（2026-09-20）

背景：两人共同推进比赛与论文，当前尚未采集数据。

决定：先建立任务、数据、实验和协作框架；初始使用私有仓库，不上传赛题原件、临时文件或真实数据。

理由：让后续实现可认领、可复核，并避免把尚未验证的研究方案表现为已有成果。

## D002：优先研究经营真实性与核查排序（暂定）

决定：以商户评估窗口为主要单位，先争取独立核验真实数据，公开底座与模拟作为补充。

限制：真实数据、申请时点、独立标签与论文创新性仍待验证；无法取得时缩小研究范围。

## 待定

- 两位成员的实际职责、协作者账号。
- 比赛截止时间与目标论文方向。
- 合作数据可得性、许可和公开范围。
- 具体技术栈、数据版本、指标阈值及计算资源。

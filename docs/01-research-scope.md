# 研究问题与边界

## 工作题目

面向小微企业授信的经营流水真实性识别与有限核查预算下的决策优化（暂定）。

## 核心问题

- RQ1：在不把正常经营波动误判为造假的前提下，交易时序、关联关系及履约证据能否提高真实性识别能力？
- RQ2：缺失数据、多源覆盖不足及异常机制变化时，方法是否稳健？
- RQ3：在固定核查预算下，风险排序或成本敏感策略能否提高有效核查产出？
- RQ4（有条件）：取得可核验收入真值后，能否估计可信经营收入及不确定性？

## 任务定义

主要预测单位为「商户 × 评估时点 × 历史窗口」。交易级标签用于定位证据，不默认从商户标签向所有交易传播。观察窗口先比较 30/90/180 天，是否可用由数据跨度和业务决定。

必须区分交易真实性、经营真实性和授信动机。没有申请事件时使用评估时点，不伪造申请日期；没有动机证据时只研究经营异常，不声称识别骗贷意图。

## 贡献候选，待文献核验

1. 带证据等级和时点可见性的数据集及评测协议。
2. 多源经营证据与关系/时序特征结合的识别方法。
3. 部分可观测条件下、面向核查预算的决策评估。

不以堆叠模型数量作为创新；先验证强基线。数据贡献和方法贡献可以择一为主，不强求同时完成。

## 可支持的结论

| 数据条件 | 允许的结论范围 |
| --- | --- |
| 独立核验真实样本 | 所覆盖人群和时段的检测与核查结果 |
| 半合成样本 | 给定背景和注入机制下的性能 |
| 完全合成样本 | 给定模拟假设下的压力测试结果 |
| 无还款、授信结果 | 不声称降低真实坏账或提高真实贷款收益 |

公开评论过滤标签、洗钱标签、拒贷和违约结果均不能直接替代本任务真值。

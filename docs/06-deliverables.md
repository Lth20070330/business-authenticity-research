# 成果组织

## 比赛报告

依据已阅读赛题 PDF，正文不超过 8 页，覆盖以下六项；最终排版和提交要求以主办方最新说明为准。

1. 数据介绍：来源、授权、字段、真值与范围。
2. 描述性分析：经营分布、异常证据、困难正常情形。
3. 模型分析：基线、方法与可解释特征。
4. 应用验证：无泄漏测试、核查预算与误差分析。
5. 产品思路：商户风险概览、证据链、核查队列、人工复核和反馈。
6. 总结结论：已证明的结果、局限和下一步。

## 论文结构草案

引言 → 相关工作 → 问题与数据 → 方法 → 实验 → 核查决策分析 → 局限与结论。

主贡献根据数据条件选择。没有独立真实验证时，定位为模拟基准或方法研究，不包装成已验证的真实授信系统。

## 拟制图表

- 数据来源与样本流转表、标签证据等级表。
- 商户时序与关系示例（脱敏或明确标注合成）。
- 主结果、消融、未知机制测试和核查预算曲线。
- 正常经营误报与模型失败案例。

## 可复现包

代码与环境版本、数据字典与来源登记、数据处理脚本、固定划分、实验配置、运行说明和结果生成脚本。不可公开的原始数据说明访问条件；可公开部分单独核对再分发权限。

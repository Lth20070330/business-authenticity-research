# 方法、仿真与评测计划

## 实现顺序

1. 数据导入、质量审计、时点截断和固定划分。
2. 可解释规则：交易集中度、收退款结构、历史波动等，阈值在验证集确定。
3. 表格基线：逻辑回归、梯度提升树；标签不足时另行评估无监督异常检测。
4. 增量引入时序和关系特征，只有证据支持时才增加图模型复杂度。
5. 核查排序与预算评估；有可靠收入真值后再做收入估计。

模型候选不等于已选技术栈，依赖版本在第一次实现时固定。涉嫌异常分数不是法律认定，也不自动作为拒贷结论。

## 特征与消融

比较交易统计、时序变化、交易对手关系、订单/履约一致性四组信息；逐组移除观察增益。记录每个特征的来源、可用时点和成本。业务规则既用来生成标签又进入特征时必须显式标明，不能将规则复现视作独立验证。

## 仿真设计

分别维护真实核验集、半合成集和完全合成集。机制来自公开案例或专家核验，保存假设、参数、随机种子和生成版本；模拟真值仅用于评估，不进入特征。

实验维度：异常强度、异常比例、正常促销干扰、缺失履约、部分资金可见、标签噪声、跨时间与未知机制。训练测试隔离机制或参数区间，并隔离生成底稿，避免只检测生成器留下的固定痕迹。

检查金额/时间分布、关系结构和业务约束，邀请业务人员盲评可行性；统计相似不能独立证明模拟具备真实有效性。不可见回流不等于不存在回流。

## 核查决策

比较随机抽查、规则排序、模型风险排序，以及有成本信息时的预期核查价值排序。预算先用核查件数，再扩展到耗时或成本。核查发现的异常金额不等同避免的贷款损失；未取得可靠成本参数时使用敏感性分析，不宣称真实利润提升。

## 指标与统计

- 识别：PR-AUC、固定误报率下召回率、精确率、校准表现。
- 决策：Precision@K、预算内检出数、确认异常金额、核查成本。
- 分组：行业、规模、时间和困难正常场景的误报率。
- 收入估计（有条件）：绝对误差及区间覆盖率。

报告多随机种子和按商户/团伙聚类的置信区间；具体重采样方案在数据可用后固定。不能把同一商户大量交易当成独立样本夸大显著性。真实测试、半合成测试、完全合成测试分表展示。

## 最小实验矩阵

| 实验 | 目的 |
| --- | --- |
| 规则 vs 表格基线 | 判断复杂方法是否必要 |
| 基础信息 vs 时序/关系/履约信息 | 验证信息增益 |
| 完整可见 vs 信息缺失 | 验证现实可用性 |
| 已知机制 vs 留出机制 | 验证泛化 |
| 多种核查预算 | 连接业务决策 |
| 真实集 vs 模拟集 | 明确外部有效性边界 |

# 实施路线与分工

以下按相对阶段规划，实际日历在确认比赛截止日期与数据条件后补充。两周先导是工作安排建议，不承诺合作数据能按时取得。

| 阶段 | A：数据与证据 | B：方法与实验 | 共同验收 |
| --- | --- | --- | --- |
| P0 定义与可行性，建议第 1–2 周 | 联系渠道清单、来源与字段盘点、案例试标 | 文献矩阵、基线方案、评测协议 | 确定数据路线、任务单位、可支持结论 |
| P1 数据先导 | 导入清洗、关联与缺失审计、双人标注 | 数据校验和固定划分接口 | 最小样本能贯通流程，证据可追溯 |
| P2 基线实现 | 检查错标及困难正常样本 | 规则、表格模型、无监督基线 | 得到第一份可复现实验记录 |
| P3 方法与仿真 | 机制依据、真实验证集维护 | 时序/关系增益、仿真与核查策略 | 独立机制测试、消融与预算曲线 |
| P4 成果整理 | 数据卡、标注质量、案例解释 | 复现脚本、图表与误差分析 | 比赛报告；视证据强度确定论文定位 |

## 阶段关口

- G0：能否取得原始记录的研究权限、关联键和独立核验信息？不满足时转向公开数据＋明确标注的模拟研究。
- G1：是否存在可信测试标签？没有时不报告真实监督检测性能，优先完成标签核验。
- G2：新方法是否稳定优于简单基线？若否，保留负结果并定位原因，不继续无目的堆模型。
- G3：是否有真实外部验证？没有时收窄论文主张，不把仿真提升等同部署收益。

## 规模原则

先以少量商户验证流程。正式规模由独立商户/团伙数量、异常率和置信区间精度决定，不以流水条数替代有效样本量。数据跨度不足时调整任务，不重复切窗口制造独立样本的假象。

# 后续模块边界

| 拟建模块 | 输入 → 输出 |
| --- | --- |
| ingestion | 授权原始记录 → 统一逻辑表与来源信息 |
| validation | 逻辑表 → 数据质量及关联审计报告 |
| labeling | 核验记录 → 证据分级标签 |
| splitting | 评估事件与实体组 → 固定划分清单 |
| features | 截止时点内数据 → 特征表与特征来源 |
| baselines | 训练特征与可用标签 → 模型与验证集配置 |
| simulation | 明确机制与背景 → 带合成来源标识的数据 |
| decision | 分数与预算/成本 → 核查队列 |
| evaluation | 预测、真值、分组 → 指标、置信区间与图表 |

按路线分步实现。导入、划分、金额聚合和时点截断的正确性需要针对性验证；不为占位文档编写空测试。
